## 本轮运行暴露并当场修复的 3 个缺陷(实录)

1. **顺序填充吃掉名额**:第一个源(腾讯)即可填满任意 limit → 改为公平采样(每源预算 ceil(limit/N) + 跨源轮转交错)
2. **section 标题式 JD 污染 company**:29/40 岗位公司名被抽成 JD 正文第一行 — `_has_labeled_lines` 不认"值为空的 section 标题行" → 修复 + discovered_company 优先于启发式推断
3. **单源故障炸全局**:宇树 SSL 瞬时抖动让整次运行崩掉 → 源级故障隔离(单源失败=诚实缺源)
