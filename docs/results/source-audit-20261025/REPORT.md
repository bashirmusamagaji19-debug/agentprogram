## 明确问题和修复优先级

1. **P0：实习条件误判。** 理想总装AI工程师原始列表明确“全职”，但正文含“有项目实习经验优先”而通过实习关键词检查；京东、吉利、优必选的3条也缺少充分类型证据。需传递并核实官方招聘类型，明确非实习类型应优先排除，不能只搜正文里的“实习”二字。
2. **P1：详情API与当前读取链未接通。** 小鹏、智元、MiniMax、生数首个候选的官方详情是在线实习，网站却因HTML失败交付0。需要同时修复详情读取、当前状态判断与可浏览链接，不能只吞掉404。
3. **P1：业务拒绝被包装成空结果。** 美团返回“请求参数格式不正确”，百度返回 `no-auth / illegal-visit`，当前来源诊断却都显示empty。应分别记录适配错误和访问拒绝。
4. **P2：发现阶段工作量过大。** 比亚迪、阶跃星辰达到90秒时限。发现层的补足、重复翻页与逐候选详情可能在运行候选处理前耗完时间。本轮日志计2491次发现层逻辑调用，底层重试和后续页面打开另计。
5. **P2：列表时效与空正文。** 蔚来10/10抽查样本已下线；携程、DeepSeek等有候选但正文抽取/条件验证未通过。必须保留这些原因，不应统一称来源无库存。

本轮只做检查与证据采集，未修改生产源码、未把修复后的单独诊断伪装成原入口通过，也未改动现有默认来源。
