## 解释限制与待改进点

- Planner规则路径60/120单元以步骤预算耗尽结束，不能将全部失败归因于模型语义能力。
- Planner部分候选耗尽终态为 candidates_exhausted，而标签使用 candidate_exhausted；其期望结果满足率还受到终态词汇不一致影响。原始次指标和bootstrap区间保留，但不把它们作为可靠的拒绝准确率或主要选型依据。
- 原报告的2000次按组bootstrap计算的是 expected_outcome_satisfied，而非本文的找满目标率；区间[0,0]只表示当前观测无差值，不证明总体等效。
- 本轮结果生成后没有调阈值/prompt或修改标签再复用同一test集。预算、停止理由和规则阅读缺陷应在后续独立开发及新版本评测中修复。
