# Streamlit 工作台整体 UI 重构设计

## 目标

把现有 Streamlit 单页从“长侧栏 + 表单 + 结果区”重构为更成熟的双栏岗位任务工作台。主路径同时服务面试演示和高频个人使用，不改变现有业务能力、字段顺序和运行流程。

## 视觉方向

采用“沉稳指挥台”：

- 深墨绿色配置栏，浅色主工作区。
- 主色为 `#117A52`，主文字为 `#16211D`。
- 所有正文、帮助文字、状态和错误文字必须满足 WCAG AA 4.5:1。
- 不使用全局侧栏颜色覆盖，避免下拉菜单、Popover 和禁用状态出现低对比。
- 卡片统一使用不超过 8px 的圆角；页面区块保持开放布局。

核心对比度：

| 用途 | 前景 | 背景 | 对比度 |
|---|---|---|---:|
| 主文字 | `#16211D` | `#F4F7F5` | 15.34:1 |
| 次级文字 | `#53645C` | `#FFFFFF` | 6.28:1 |
| 品牌绿 | `#117A52` | `#FFFFFF` | 5.34:1 |
| 配置栏主文字 | `#EAF4EE` | `#10271E` | 14.03:1 |
| 配置栏次级文字 | `#AEC3B7` | `#10271E` | 8.48:1 |
| 警告 | `#9A5A0A` | `#FFFFFF` | 5.47:1 |
| 错误 | `#B42318` | `#FFFFFF` | 6.57:1 |

## 信息架构

1. 顶部工作栏：品牌、运行状态、当前数据模式摘要。
2. 左侧配置栏：历史运行、数据来源、模型能力、搜索条件、候选人信息、运行按钮，字段顺序保持不变。
3. 右侧主工作区：岗位结果优先，随后才是诊断、执行轨迹和下载。
4. 首次进入时，右侧显示简洁空状态，说明一次运行会产出什么。
5. 移动端改为上下布局，配置区在上，结果区在下。

## 组件

- `ui-workspace-header`: 顶部品牌与状态。
- `ui-config-panel`: 左侧配置工具区。
- `ui-result-shell`: 右侧结果区域。
- `ui-empty-state`: 首次运行空状态。
- `ui-run-pill`: 数据模式与状态标签。
- 保留现有指标网格、岗位表格、诊断表、轨迹表和下载按钮。

## 行为边界

- 不改变 `UiRunRequest`、workflow、持久化或 artifact 行为。
- 不删除、合并或改变任何输入字段和操作顺序。
- 历史运行继续按 owner 隔离并显示最近 10 条。
- 结果区第一 Tab 必须是“岗位结果”。
- 运行失败、部分成功和 Demo 数据提示继续明确显示。

## 测试与验收

- 关键颜色对满足至少 4.5:1。
- CSS 不包含 `[data-testid="stSidebar"] *` 这类全局覆盖。
- AppTest 首次运行页面同时出现“配置任务”和“运行结果”。
- 现有 568 个测试继续通过。
- 桌面和 390px 移动视口无文本重叠或横向溢出。
